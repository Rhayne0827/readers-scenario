# Memory

- The visual language is dark editorial fantasy: ink black, parchment ivory, muted antique gold, crimson danger, and cyan observer accents.
- Babylon is installed and initialized once in `GameCanvas.tsx`; the narrative UI is intentionally HTML/CSS for crisp readability.
- Uploaded assets use `/manus-storage/` paths and are not committed into the project tree.
- `pnpm check` passes after the MVP implementation.
- The browser interaction pass verified that the first choice updates Story Sense, coins, Sponsor Log, and transitions to the continue state.
